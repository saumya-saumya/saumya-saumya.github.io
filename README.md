# Saumya S. — professional portfolio

Public portfolio: https://saumya-saumya.github.io/

Financial-data engineering experience, earlier machine-learning work and selected educational projects. The October 2026 redesign updates the college-era homepage while retaining the earlier assets and repository history.

## Current site

The homepage uses `index.html`, `portfolio-2026.css` and `portfolio-2026.js`. It is a buildless static site, published by GitHub Pages from `master` / root. No package installation, backend, model service or API keys are needed to run it.

```text
python -m http.server 8766
```

Open http://localhost:8766/. The `/trade-state-lab/` link points to a separately published GitHub project site and is available on the public domain.

Features include project filters, two clearly labeled synthetic trade-state examples, an explorable data-engineering decision flow, native expandable experience entries, a quick professional overview, theme switching, accessible mobile navigation and reduced-motion support. The main content and ordinary links remain available without JavaScript. Clipboard and theme storage are optional browser features with fallbacks.

## Content boundaries

Professional experience is separate from educational demonstrations. Trade State Lab is an AI-assisted synthetic example, not a claim of production LLM deployment or measured AI accuracy. Historical project repositories are labeled with their period; their runtime compatibility is not implied. Preview graphics are illustrative, not project metrics. No employer data or code is included in the redesign.

Earlier assets and the old build configuration remain preserved for history; the new homepage does not import the old Bootstrap/jQuery stack. Previous versions can be inspected in Git history. Personal portfolio; no employer endorsement implied.
